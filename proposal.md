## Description
 For my final project I will create an Procedual Asset package for Houdini and Unreal Engine. The main goal is to create a custom UI and tools to help animators and game developers with houdini and unreal engine. The tools for houdini will be for simple world building, and also to simplify common houdini modeling techniques. The tools for unreal engine will be for simplifying overcomplicated world building techniques. 

## Features
- Feature 1
	- I will research and brainstorm common problems and roadblocks for houdini and unreal engine artists. ( I will also base my ideas  on my notes from other classes, and speaking with other devs and animators)
- Feature 2
	- I will research and create tools (in visual studio code/ using the built in python extenstion in both programs) and then I will develop buttons, and custom nodes.
- Feature N 
	- Afterwards I will test all tools to see which can be improved, and which can be scrapped all together until I have put together a final composition. (I will even have friends test it out as well)

## Challenges
- How to create a custom node using python. (Houdini)
- How to create a custom functional button using python (unreal engine).
- basics of a useful functioning UI design.
